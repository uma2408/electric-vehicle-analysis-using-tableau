# 🚗 Electric Vehicle Analysis — Tableau Dashboard

## 📌 Project Overview

This project is an interactive **Tableau dashboard** created to analyze electric vehicle (EV) population data.

The dashboard provides insights into electric vehicle adoption, manufacturers, vehicle models, electric vehicle types, electric range, and year-wise growth.

The project was created as part of my **Data Analytics portfolio** to demonstrate practical skills in data visualization, exploratory data analysis, and dashboard development using Tableau.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze the growth of electric vehicles across different model years.
* Identify the leading EV manufacturers.
* Analyze the most common electric vehicle models.
* Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
* Analyze the average electric range of electric vehicles.
* Understand the distribution of electric vehicles across different locations.
* Build an interactive dashboard to communicate insights clearly.

## 📈 Dashboard Analysis

The Tableau project contains the following analyses:

### 1. Top 10 Total Vehicles by Make

Identifies the manufacturers with the highest number of electric vehicles in the dataset.

### 2. Average Electric Range

Analyzes the average electric driving range of the vehicles.

### 3. Total BEV Vehicles

Shows the total number of **Battery Electric Vehicles (BEVs)**.

### 4. Total PHEV Vehicles

Shows the total number of **Plug-in Hybrid Electric Vehicles (PHEVs)**.

### 5. Total Vehicles

Provides the overall number of electric vehicles represented in the dataset.

### 6. Total Vehicles by Model

Analyzes the distribution of electric vehicles across different vehicle models.

### 7. Total Vehicles by Model Year

Shows how the number of electric vehicles changes across different model years.

### 8. Interactive Dashboard

Combines the key analyses into an interactive Tableau dashboard, allowing users to explore the data and identify trends.
